# 样式调试面板

双击项目根目录的 `调试桌面版 Metrio.cmd`，或者运行 `调试 Metrio.cmd` 后访问本地开发地址。面板只在这些开发入口挂载，普通入口和便携包不加载它。

- **滚轮与动画**：最大倾斜角 0–90°、动画时长 0–3000 ms、缓动曲线、透视距离 80–5000 px、单位行高 24–240 px、边缘渐隐 0–50%。默认倾斜仍为 5°。
- **文字**：单位名称、候选数字、高亮数字、符号字号和文字右侧留白。
- **配色**：主题红色、主要文字、候选文字、数字键背景。
- 滑块实时预览，也可直接输入数值。预览草稿保存在当前环境的 `metrio.dev.styles.v1`，不改收藏、历史或算式。
- **保存并应用**：将当前调整写入程序，普通入口与移除菜单后也能沿用。
- “启用样式预览”可暂时回到程序已保存的样式，再勾选即可继续预览；“重置预览”丢弃未保存的调整，回到最近保存的样式。
- `Ctrl+Shift+D` 或右上角 × 收起 / 展开；⇄ 切换左、右停靠位置。面板内的 `Esc` 只收起面板，不清空算式。

## 固化样式

点击 **保存并应用** 即可，无需复制 CSS。保存会写入独立的 `src/user-styles.css`，立即应用于当前页面，并同步到 `dist/Metrio/www/src/user-styles.css` 及桌面完整性清单。普通桌面窗口重开后使用新样式；如果尚未构建桌面版，先保存项目，再构建即可。已生成的 ZIP 是构建时的快照，再次构建会将新样式打包。

正常应用直接加载这份样式，不需要 `devtools`、localStorage 或开发服务器。保存只包含已调整的属性，保留其他响应式默认规则。保存失败会显示原因、保留预览，并回滚已替换的文件。`导出 CSS` 保留为可选的备份、分享方式。

浏览器入口通过仅接受同源请求的本地开发服务器写入；Windows 调试入口通过原生宿主写入。两者使用同一份 `style-schema.json` 校验范围，只允许写入固定的样式文件和对应清单。普通桌面模式不接受写入请求。

动画和圆柱参数是应用自身支持的 CSS 变量：`--wheel-max-angle`、`--wheel-duration`、`--wheel-easing`、`--wheel-perspective`。应用有独立默认值和参数范围校验，不依赖本目录。系统减少动态效果的偏好优先。

文字范围：单位名称 6–48 px、候选数字 10–120 px、高亮数字 12–160 px、单位符号 6–64 px、右侧留白 0–128 px。极端值可用于调试，可能造成文字拥挤或遮挡。

## 隐藏与移除

1. 临时收起：使用面板按钮或 `Ctrl+Shift+D`，样式预览继续保留。
2. 使用正常界面：运行 `启动桌面版 Metrio.cmd` 或直接打开 `index.html`。浏览器开发地址加 `?debug=0` 也可完全关闭面板。
3. 整体移除：删除 `devtools` 目录后重新打开调试入口；加载器会检查文件是否存在，缺少目录时仍打开正常换算界面。可选面板测试会自动跳过，常规应用测试继续运行。
4. 在已打开的开发页面即时卸载：在开发工具执行 `window.MetrioStylePanel?.destroy()`。它会移除面板、未保存的预览样式和全局快捷键；已经“保存并应用”的样式继续生效。预览草稿可在下次挂载时恢复。

面板使用 Shadow DOM 隔离样式和输入事件。`index.html` 和换算代码没有面板加载代码；只有开发服务器与 Windows 的 `--dev` 启动路径有可选挂载逻辑。桌面构建使用文件白名单，完整性检查会拒绝包含 `devtools` 的便携包。
