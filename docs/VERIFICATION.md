# 测试与验证记录

以下保留各版本交付时的验证记录。测试执行方法见[开发说明](DEVELOPMENT.md)。

## 验证范围

程序测试、DOM 集成测试与资源检查可在 Windows Node.js 下运行。DOM 集成测试仅在 Node 进程中构造文档和事件，没有真实布局引擎，不等同于真实页面渲染或显卡合成检查。

已完成的桌面检查针对本机 Windows 与 WebView2。其他 Windows 电脑、其他 DPI 和多显示器组合、iPhone 实机以及 PWA 安装尚未验证；浏览器中的手机宽度检查不等同于 iPhone 实机验证。

## 0.5.0

0.5.0 增加分区图标分类首页，65 项自动化测试通过，覆盖启动菜单、71 个分类唯一归属、菜单与换算页面往返、单位搜索、设置联动和收藏入口。真实浏览器已检查桌面、390 px 与 320 px 宽度；验证了分区跳转仅滚动内部列表、32°F 换算为 0°C，以及关闭分类后首页立即移除图标。手机宽度未发现横向溢出。Windows 普通模式和开发模式均使用独立配置启动到首页（page=home），15 个打包文件检查通过，已保存样式文件的 SHA-256 保持不变。本轮不涉及换算系数变更。

## 0.4.0

0.4.0 通过 62 项自动化测试，覆盖新增参考换算值、71 类渲染、单位开关持久化、筛选后的滚轮选择、收藏与历史保留及样式保存回归。真实浏览器中验证了齿轮与二级菜单、单位开关重载保留、配速换算，以及 390 px 宽度下管理页无横向溢出。Windows 普通模式与开发模式均使用独立测试配置成功启动，加载 71 类、736 个条目；开发模式也成功加载样式面板。便携包的 15 个文件及 x64 架构检查通过，保存样式文件的 SHA-256 与本轮修改前一致。

## 0.3.0

0.3.0 的 44 项测试通过，新增开发样式实时应用、暂停与重置、键盘事件隔离、参数恢复、面板卸载后继续换算、导出 CSS 独立生效，以及删除可选工具目录后开发页面仍可用的检查。实际浏览器验证了行高与字号调整、预览开关、CSS 导出、快捷键收起 / 展开和 `?debug=0` 停用入口。Windows 普通启动、带面板的开发启动、缺少 `devtools` 的开发启动均在隔离数据目录通过；14 个便携文件完整性检查通过，分发包不包含调试菜单。

## 0.2.5

0.2.5 的 37 项自动测试通过，覆盖圆柱中央无变形、上下相反倾斜、白字与候选层逐帧同步、连续滚动及紧凑行高。实际浏览器检查了桌面与手机宽度、点击倾斜单位、方向键回转和单次滚轮切换；72px 的中央行保持原高度，上下相邻行投影高度约 29px。14 个打包文件通过完整性检查，新 Windows 程序在隔离数据目录启动并收到 18 类、130 单位的界面就绪消息。

## 0.2.3

0.2.3 更名后 29 项测试通过；新 `Metrio.exe` 的产品名、文件描述与版本信息已核对，14 个打包文件通过哈希和资源一致性检查，原生程序成功启动并收到 18 类、130 单位的界面就绪消息。旧 VERT 构建保存在 `.local/legacy-builds/`，当前分发目录只保留 Metrio 构建。

## 0.2.1

0.2.1 的 25 项自动测试已通过，新增滚动边界、末端选择、固定显示内容同步、选中前后候选行样式稳定、缩放后滚动结束事件的回归检查。普通与兼容入口都在隔离测试数据目录下启动，并收到界面就绪消息；14 个打包文件的完整性检查通过。本轮 Computer Use 自动许可检查连续超时，未能进行新版本的真实窗口滚动与残影视觉验收；不将自动测试通过或启动就绪视为这类瞬态画面问题已完全消失。

## 0.2.0

0.2.0 已通过 22 项程序/DOM 测试，以及便携版文件哈希、资源一致性、x64 可执行文件与加载器检查。已在本机启动实际 Windows 窗口，检查桌面布局、手机预览与分类菜单，并验证算式输入、长度与温度换算、复制后的成功提示与历史记录、收藏和上次输入重启保留。调试模式的文件变更自动刷新已验证。实测中修复了较矮窗口下键盘底部被裁切的问题。
