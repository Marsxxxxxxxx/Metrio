# Metrio 使用指南

## Windows 桌面版

在项目根目录双击 `启动桌面版 Metrio.cmd`，或直接运行 `dist/Metrio/Metrio.exe`。桌面版使用独立窗口，支持缩放、最大化，并记住窗口大小、位置和上次换算。正常使用不需要 Node.js、开发服务器或单独的浏览器窗口。

便携包位于 `dist/Metrio-<版本号>-windows-x64.zip`。解压后运行其中的 `Metrio/Metrio.exe`。移动或复制时请保留整个 `Metrio` 文件夹，包括 DLL 和 `www`，不能只复制 EXE。

运行环境为 Windows 10/11 x64、.NET Framework 4.8 和 Microsoft Edge WebView2 Runtime。便携包未捆绑 WebView2；缺少运行时时，可安装 [Microsoft 官方 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

当前提供 Windows 桌面版和本地网页版；手机宽度预览不是 iOS 安装包，iPhone 与 PWA 安装尚未验证。

## 选择分类与换算

1. 打开软件后，在分类首页选择图标。分类按六个区域排列，顶部按钮可跳转到对应区域。
2. 搜索支持分类名称和已开启的单位。搜索单位后点击分类，会选中对应的输入单位。
3. 在换算界面滚动两列单位，或点击候选单位；红色折角条表示当前选中项。
4. 输入数值或算式即可换算。支持四则运算、括号和科学记数法。
5. 点击“交换”可交换输入与输出单位，同时保持当前物理量。点击“复制结果”可复制带单位的结果。

换算界面左上角返回分类菜单，搜索和浏览位置会保留。首页的“继续上次换算”可恢复上次的单位组合与输入。

## 收藏、记录与显示

- 点击键盘上的星标收藏当前单位组合，在首页或侧栏的“我的收藏”中调用。
- 点击 `=` 或成功复制结果后保存记录，最多保留最近 30 条；点击记录可再次使用对应算式和单位。
- 齿轮设置可调整小数显示精度与千位分隔符。
- 窗口较宽时，顶部可切换桌面和手机宽度预览；窄屏分类菜单自动采用三列图标。

## 管理分类与单位

从右上角齿轮进入“设置 → 单位管理”，或使用首页底部的“管理分类与单位”。

可以搜索全部单位、逐项勾选、开关整个分类，并使用“本类全选”“仅常用”或“全部开启”。修改即时生效并保留。主搜索和滚轮只使用已开启的内容，单位管理可搜索包括已关闭项目在内的全部定义。

每类至少保留两个单位，也可关闭整个分类；始终保留至少一个分类。关闭分类后，首页移除对应图标；一个区域没有开启的分类时会自动隐藏。关闭当前输入单位时，程序尽可能保持原来的物理量。

关闭单位不会删除相关收藏或历史记录。这些条目会暂时无法调用，重新开启对应单位后即可继续使用。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| `Ctrl+K` | 返回分类菜单并聚焦搜索 |
| 数字、`+ - * /`、括号 | 在换算界面输入算式 |
| `Enter` | 计算并保存记录 |
| `Esc` | 清空换算输入 |
| `Backspace` | 删除末尾字符 |
| `F` | 在输入框外收藏或取消收藏当前换算 |
| `S` | 在输入框外交换单位 |
| `↑` / `↓` | 单位列获得焦点后选择相邻单位 |
| `PageUp` / `PageDown` | 单位列获得焦点后移动三个单位 |

分类首页不会响应换算数字、收藏或交换快捷键。样式调试面板的快捷键另见[样式调试说明](../devtools/README.md)。

## 浏览器版

双击项目根目录的 `启动 Metrio.cmd`，或用 Chrome / Edge 打开 `index.html`。此入口不需要服务器或 Node.js。浏览器开发预览的启动方法见[开发说明](DEVELOPMENT.md)。

## 数据保存

桌面版的收藏、最近记录、单位开关、显示设置和窗口信息保存在 `%LOCALAPPDATA%\Vert`。旧目录名、内部本地域名和存储键用于兼容更名前的数据，界面与程序名称均为 Metrio／度衡。替换程序文件不会清空这些数据。

浏览器版使用当前浏览器的 localStorage。`file://`、`http://`、不同浏览器与桌面版之间不共享数据。直接打开本地文件时，存储是否随文件夹改名保留取决于浏览器对文件来源的处理；需要稳定保存时可使用桌面版。浏览器禁止存储时，仍可换算，但设置无法保留。

## 滚动闪烁或残影

先关闭所有 Metrio 窗口，再运行项目根目录的 `兼容模式 Metrio.cmd`；便携包内的入口为 `Metrio Compatibility.cmd`。

兼容模式通过 WebView2 的 `--disable-gpu` 参数使用软件渲染，仅作用于 Metrio，与普通模式共用收藏和记录，但可能增加 CPU 占用。关闭程序后重新运行普通入口即可恢复默认渲染。切换前需关闭其他窗口，避免同一 WebView2 数据目录使用不同启动参数而产生冲突。

兼容模式用于排查显示问题，不表示已确认显卡或驱动是残影原因。已完成的检查及其范围见[验证记录](VERIFICATION.md)。
