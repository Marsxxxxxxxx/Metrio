# Metrio · 度衡

**度衡（Metrio）** 是一款红白配色的个人单位换算工具，界面参考 Andrej Mihelic 的经典 VERT 设计。当前版本为 **0.2.3**，提供 Windows 桌面便携版与本地网页入口，共用换算引擎和 UI。项目目录为 `D:\WorkFlow\Projects\Metrio`。

## Windows 桌面版

双击项目目录中的 **`启动桌面版 Metrio.cmd`**，或直接运行 **`dist\Metrio\Metrio.exe`**。

这是独立窗口应用，具有任务栏图标，支持缩放、最大化，并记住窗口大小、位置和上次换算。普通使用不需要 Node.js、开发服务器或浏览器窗口。代码、图标和换算定义均在本地。

便携压缩包位于 **`dist\Metrio-0.2.3-windows-x64.zip`**。移动到其他目录或电脑时，请保留整个 `Metrio` 文件夹，包括 DLL 和 `www`，不能只复制 EXE。

运行环境：Windows 10/11 x64、.NET Framework 4.8、Microsoft Edge WebView2 Runtime。本机已验证可以启动；其他电脑若缺少 WebView2，可安装 [Microsoft 官方 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。本包未捆绑该运行时。

桌面版的收藏、最近记录、设置和窗口信息继续使用 `%LOCALAPPDATA%\Vert`。这里的旧名称、内部本地域名和存储键是兼容标识，用于保留更名前的数据；界面与程序名称已改为 Metrio／度衡。它们与浏览器版的数据独立，替换程序文件不会清空这些数据。浏览器直接打开 `file://` 时，存储是否随文件夹改名保留取决于浏览器对文件来源的处理；需要稳定存储时使用桌面版。

若滚动时仍有闪烁或残影，先关闭所有 Metrio 窗口，再运行 **`兼容模式 Metrio.cmd`**；便携包内的同一入口是 **`Metrio Compatibility.cmd`**。此模式通过 WebView2 参数 `--disable-gpu` 使用软件渲染，仅作用于 Metrio，与普通模式共用收藏和记录，但可能增加 CPU 占用。再次运行普通入口即可恢复默认渲染；切换前关闭其他窗口，以免同一 WebView2 数据目录的不同启动参数冲突。

## 0.2.3 正式命名

- 项目与程序名称为 Metrio，中文名为度衡；窗口标题、页标题、关于页、启动文件、可执行文件和分发包统一命名。
- 原 V 字图标更新为红底白色 M 图标，保留红白配色。
- 数据目录和存储兼容标识延续原值，桌面版收藏、历史与设置可直接沿用。

## 0.2.2 滚轮步长修复

- 离散鼠标滚轮输入按方向切换相邻一个单位，阻止系统默认滚动距离再次移动列表，避免单次跳过两个单位。
- 连续多次滚动逐次处理，不使用吞掉快速输入的时间限流；反向滚动立即响应，列表首尾不越界。
- 连续的小幅像素输入及其惯性阶段保留原生滚动。设备类型按事件特征判断，尚未覆盖所有鼠标和触控板。
- `Ctrl` / `Meta` 缩放、`Shift` 和横向输入保持浏览器默认行为。

## 0.2.1 滚动显示修复

- 红色条中的当前单位与结果固定居中，滚动的候选行保持稳定的颜色、字号和数字显示规则。避免滚动途中白字落入白色背景，以及字体变化引起的视觉跳动。
- 同一帧内合并滚动选择更新，滚动结束时复核最终单位，避免窗口缩放与滚动同时发生时漏掉选择更新。
- 新增可选的软件渲染启动入口，供桌面残影排查使用。没有将显卡或驱动确认为残影来源。

## 使用方式

- 鼠标滚动两列单位，或者点击单位行；红色折角条表示当前选中项。
- 直接按数字键输入，支持 `+ - * /`、括号和 `Enter`。
- `Esc` 清空，`Backspace` 退格。输入框外 `F` 收藏、`S` 交换单位，`Ctrl+K` 搜索。
- 点击星标保存当前单位组合；`=` 或成功复制结果时保存记录。
- 顶部可以切换桌面和手机宽度；手机模式通过左上角菜单进入分类。
- 设置支持小数显示精度和千位分隔符。仅提供红白配色。

## 调试桌面 UI

双击 **`调试桌面版 Metrio.cmd`**。此模式直接读取项目内的 `index.html`、`src/` 和 `assets/`；修改并保存界面文件后自动刷新，无需重新编译窗口程序。

- `F12`：打开 WebView2 开发工具。
- `Ctrl+R`：刷新界面。
- 顶部“手机”：在 Windows 窗口内预览手机宽度，便于调整原版红白布局。

修改完成后，运行下列命令更新便携版与 ZIP：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-desktop.ps1
node scripts/check-desktop.cjs
```

构建使用 Windows 自带的 .NET Framework C# 编译器。首次构建从 NuGet 下载固定版本的 Microsoft WebView2 SDK，并核对 SHA-256；后续使用 `.local/webview2/` 缓存，无需安装完整 .NET SDK。`desktop/Program.cs` 是原生窗口，`desktop/App.config` 配置 DPI，`scripts/build-desktop.ps1` 编译和打包。

## 浏览器版

双击 **`启动 Metrio.cmd`**，或用 Chrome / Edge 打开 **`index.html`**。此入口不需要服务器或 Node.js。

浏览器版的收藏、历史和设置保存在当前浏览器的 localStorage 中。`file://`、`http://`、不同浏览器与桌面版之间不共享数据。在浏览器禁止存储时，仍可使用换算，但配置无法保留。

双击 **`调试 Metrio.cmd`**，然后在浏览器打开终端打印的地址（默认 `http://127.0.0.1:4173`）。该入口查找已安装的 Node.js，也支持当前机器上的 Codex 捆绑 Node.js。

也可以在项目目录执行：

```powershell
node scripts/dev-server.cjs
```

仅监听本机回环地址。修改 HTML、CSS 或 JavaScript 后页面自动刷新。使用 `Ctrl+C` 停止。若端口被占用，可执行 `node scripts/dev-server.cjs 4174`。

## 当前范围

- 18 类：长度、质量、温度、面积、体积、速度、时间、数据容量、压力、能量、功率、角度、频率、力、扭矩、体积流量、密度、油耗。
- 双列选择、数值转换、四则运算、分类 / 单位搜索、收藏、最近 30 条记录、复制结果。
- 桌面布局与 390px 手机布局；移动端窄屏自动使用单列。
- 首版未接入实时汇率、衣物尺码、配料体积转重量、攀岩评级和复合单位。
- 当前交付为 Windows 桌面版与本地网页。尚未进行 iPhone / PWA 安装验证，也不是 iOS 安装包。

## 文件位置

- `index.html`：应用结构与入口。
- `src/styles.css`：红白配色、排版与响应式布局；开头的 CSS 变量用于调整主色和行高。
- `src/app.js`：界面行为、滚动、输入、收藏和本地记录。
- `src/engine.js`：单位定义与换算引擎、算式解析、数值格式化。
- `scripts/dev-server.cjs`：零依赖的本地开发服务器。
- `desktop/`：Windows 原生窗口、运行配置与便携版说明。
- `scripts/build-desktop.ps1`、`scripts/check-desktop.cjs`：桌面版构建、打包与完整性检查。
- `tests/`：换算、算式和本地资源检查。
- `docs/REFERENCES.md`：设计来源、单位定义与验证边界。

## 验证

正常使用和本地调试服务器均不需要安装 Node.js 依赖。完整测试中的 DOM 集成测试使用开发依赖 `happy-dom`；在新环境先执行 `npm install` 或 `pnpm install`。

```powershell
node --test tests/*.test.cjs
node --check src/app.js
node --check src/engine.js
```

测试覆盖固定参考值、单位往返、温标偏移、绝对零度、油耗倒数、美英制体积、十进制 / 二进制数据容量、算式优先级及非法输入。DOM 集成测试覆盖页面启动、数字键盘、单位搜索、交换、收藏持久化、历史、设置、复制成功与拒绝后的手动复制路径；该测试环境没有实际布局引擎。

0.2.0 已通过 22 项程序/DOM 测试，以及便携版文件哈希、资源一致性、x64 可执行文件与加载器检查。已在本机启动实际 Windows 窗口，检查桌面布局、手机预览与分类菜单，并验证算式输入、长度与温度换算、复制后的成功提示与历史记录、收藏和上次输入重启保留。调试模式的文件变更自动刷新已验证。实测中修复了较矮窗口下键盘底部被裁切的问题。

上述验证针对本机 Windows 与 WebView2。其他 DPI、多显示器组合、其他 Windows 电脑和 iPhone 尚未实测；DOM 测试不等同于真实页面渲染测试。

0.2.1 的 25 项自动测试已通过，新增滚动边界、末端选择、固定显示内容同步、选中前后候选行样式稳定、缩放后滚动结束事件的回归检查。普通与兼容入口都在隔离测试数据目录下启动，并收到界面就绪消息；14 个打包文件的完整性检查通过。本轮 Computer Use 自动许可检查连续超时，未能进行新版本的真实窗口滚动与残影视觉验收；不将自动测试通过或启动就绪视为这类瞬态画面问题已完全消失。

0.2.3 更名后 29 项测试通过；新 `Metrio.exe` 的产品名、文件描述与版本信息已核对，14 个打包文件通过哈希和资源一致性检查，原生程序成功启动并收到 18 类、130 单位的界面就绪消息。旧 VERT 构建保存在 `.local/legacy-builds/`，当前分发目录只保留 Metrio 构建。
