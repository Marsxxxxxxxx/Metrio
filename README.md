# Metrio · 度衡

**Metrio（度衡）** 是一款红白配色的个人单位换算软件，覆盖日常生活、工程与科学领域。它提供 Windows 独立桌面版和本地网页版，换算在本机完成，无需联网。

## 可以做什么

- **单位换算**：通过双列滚轮选择输入与输出单位，即时显示结果；支持交换单位和复制结果。
- **算式计算**：直接输入数值或包含四则运算、括号、科学记数法的算式，再换算为目标单位。
- **分类查找**：使用分区图标菜单浏览分类，或按分类名称、单位名称及符号搜索。
- **自选单位**：单独开启或关闭单位、隐藏整个分类，也可一键保留常用单位，让菜单和滚轮只显示需要的内容。
- **收藏与记录**：收藏常用换算组合，保留最近 30 条换算记录，并继续上次的换算。收藏、记录与设置保存在本地。
- **显示调整**：设置结果精度和千位分隔符。界面支持桌面与手机宽度布局，提供平滑滚动和圆柱透视效果。

## 换算范围

目前提供 **71 个分类、736 个单位条目**，按六个区域组织：

| 区域 | 分类数 | 主要内容 |
| --- | ---: | --- |
| 日常生活 | 13 | 长度、质量、温度、面积、体积、时间、速度、油耗、厨房容量、数量、数据容量、数据速率、排版长度 |
| 运动与力学 | 15 | 配速、加速度、角度、角速度、频率、力、扭矩、压力、流量、动量、转动惯量等 |
| 电学与磁学 | 13 | 电荷与电池容量、电流、电压、电阻、电导、电容、电感、磁通量、电场与磁场等 |
| 能量与热学 | 11 | 能量、功率、温差、热容、比热容、热导率、传热系数、热阻、热流密度、能量密度与比能量 |
| 材料与化学 | 10 | 密度、比容、黏度、物质的量、摩尔浓度、摩尔质量、比例、纱支与面料克重 |
| 光学与天文 | 9 | 照度、亮度、发光强度、光通量、天文距离、放射性活度、吸收剂量、当量剂量与剂量率 |

单位库包含公制、市制、英美制及专业单位，并区分不同容量制式、十进制与二进制数据单位、绝对温度与温差。除比例换算外，还支持温标偏移、油耗与配速的倒数换算，以及 dBm / dBW 对数功率换算。

同一单位可能出现在不同用途的分类中，例如“体积”和“厨房容量”；736 为各分类中的单位条目总数。
